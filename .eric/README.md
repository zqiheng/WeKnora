# WeKnora 源码分析笔记

> 本目录是个人对 WeKnora（腾讯 RAG 框架，Go 后端 + Vue 3 前端）源码的阅读笔记，按主题拆分成多篇文档。每篇都从**代码基准**出发，梳理某条链路的实现原理、数据流与关键文件索引。
>
> 代码基准：`internal/`（后端）、`frontend/src/`（前端）、`config/`（配置与提示词）。

## 基础功能 vs 增强功能

判据：**能跑通「提问 → 检索 → 回答」最小闭环的 = 基础功能；叠在它之上让答案更准/更全/更快/更可信的 = 增强功能**。增强功能之间解耦、可独立开关，各解决一个具体质量问题。

### 基础功能（最小闭环，缺一不可）

| 环节 | 功能 | 对应文档 |
| --- | --- | --- |
| 入库 | 文档解析（格式 → Markdown） | [不同格式文档处理流程](不同格式文档处理流程.md) |
| 入库 | 文本分块 | [文本解析分块详解](文本解析分块详解.md) |
| 入库 | 向量化 + 建索引 | [文档入库处理流程](文档入库处理流程.md) |
| 检索 | 向量检索 | [问题检索与QA回答流程](问题检索与QA回答流程.md) |
| 生成 | 上下文组装 + LLM 回答 | [问题检索与QA回答流程](问题检索与QA回答流程.md) |
| 输出 | 流式输出（SSE，体验增强，可降级为「算完再返回」） | [问答SSE流式传输与前端实时渲染](问答SSE流式传输与前端实时渲染.md) |

```text
                        ┌─────────────────────────────────────────┐
  增强层（可选，加质量）   │ 知识图谱 · LLM Wiki · FAQ · 多模态 · 记忆  │
                        │ 意图识别 · 查询改写 · 问题推荐 · 标签 · 网页搜索 │
                        │ 混合检索 · RRF · 重排 · MMR · 父块子块     │
                        └───────────────────┬─────────────────────┘
                                            │ 叠在上面
                        ┌───────────────────▼─────────────────────┐
  基础层（最小闭环）      │ 文档解析 → 分块 → 向量化 → 向量检索        │
                        │       → 组装上下文 → LLM 回答 → 流式输出    │
                        └─────────────────────────────────────────┘
```

> **横切关注点**：`Prompt模板`（所有 LLM 调用输入的来源）是基础层的地基；`Langfuse` 是可观测性增强。两者不改变答案内容，属「管道」。

## 阅读建议

1. **先看主干**：《问题检索与QA回答流程》→《问答SSE流式传输与前端实时渲染》，建立「一条请求怎么从头走到尾」的整体观。
2. **再补两翼**：《意图识别与查询改写》（检索前）+《检索质量深度剖析》（检索中）决定答案质量。
3. **离线侧**：从《文档入库处理流程》进入，按需深入《不同格式文档处理流程》《文本解析分块详解》。
4. **横切**：《Prompt模板格式与设计》理解所有 LLM 调用的输入从哪来；《Langfuse链路追踪》理解整条链路的可观测性。
